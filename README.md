An entry for make.fun's [gta6-trophy-rarity-forecast-01](https://make.fun/c/gta6-trophy-rarity-forecast-01): a program that forecasts, for every Grand Theft Auto VI PlayStation 5 trophy, the percent of Exophase-tracked players who will have earned it one week after launch (2026-11-26T00:00:00Z), as five quantiles per trophy. It reads a case file of recorded reads of the game's Exophase trophy page and writes the forecast in the case's output format.

The entrypoint is `main.ts` (Node 22) or `main.py` (Python 3.13), standard library only, deterministic, no network.
